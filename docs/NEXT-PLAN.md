## Сделано вне плана (по ходу работы)

Этих пунктов в плане не было — они вылезли из ваших замечаний:

- **Своё окно пишется как активность** (`CarpeDiem`): раньше просмотр статистики
  оставлял дыру в дне и «Idle» в шапке.
- **Работа считается по приложению ИЛИ домену**: «Сегодня» показывало 171 мин
  там, где «Неделя» — 247, потому что браузерная работа терялась.
- **Тултипы ленты дня**: время с секундами, приложение, заголовок, ссылка, тег;
  у созвона — код встречи.
- **Склейка созвонов** после перезапуска (разрыв ≤ 2 мин): один звонок больше не
  распадается на два огрызка.
- **Пустая очередь «без тега» скрыта** — блок не занимает место ради «всё размечено».
- **Единая палитра цветов** (`lib/colors.ts`): карточка дня, легенда, теги и KPI
  недели больше не расходятся; «не записано» переведено на янтарный.
- **Честные формулировки**: «приложение не работало» → «нет событий».

- **C4** делает главный экран читаемым: сейчас структуру дня видно только по

- **D** — последними: новые экраны поверх нечестных данных будут красиво врать.
