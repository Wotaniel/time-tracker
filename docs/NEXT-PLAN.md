## Порядок

`A` → `B` → `C` → `E` → `D`.

`A` первым, потому что после неё `B` и `C` можно менять без страха. `E`
перемешана между этапами как быстрые победы. `D` — только когда данные
честные: иначе новые экраны будут показывать неверные числа с новым дизайном.

## Чего не делаем

- Productivity score без расшифровки расчёта.
- Новые графики, не отвечающие на вопрос «что делать».
- Синхронизация и облако: приложение локальное по контракту из `PRD.md`.
