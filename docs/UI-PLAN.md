# UI Plan

План перестройки интерфейса CarpeDiem. Основан на разборе информационной
архитектуры RescueTime, Toggl, Clockify, Timely, Rize, Timing, ManicTime,
ActivityWatch и Apple Screen Time.

## Диагноз: проблема в иерархии, а не в наборе фич

Факты по коду на момент составления плана:

| факт | чем плохо |
|---|---|
| 4 иконки без подписей в сайдбаре | «Работа» не читается без hover |
| на «Сегодня» три изображения одних и тех же данных: шкала дня (`h-12`), список приложений с барами, хронологический список событий | самая ценная визуализация — самая мелкая; список событий по 3 секунды занимает пол-экрана |
| пять блоков одного веса (одна рамка, один фон, один `p-4`) | глазу не за что зацепиться: `text-3xl` итога конкурирует с `text-sm` заголовков |
| итог дня показан дважды — в карточке и внутри `LogView` | непонятно, какая цифра главная |
| цвет приложения = хеш на 8 оттенков | цвет не значит ничего: ни категорию, ни тег, ни работу |
| теги за меню `⋮` | главное действие разметки спрятано |
| «Статистика» — 4 блока, включая heatmap | heatmap не отвечает ни на какой вопрос |
| «Работа» — отдельный экран с теми же данными под фильтром | выдуманный раздел |

## Принципы, которые подтверждены конкурентами

1. **Один герой на экран.** Toggl — таймер, RescueTime — Time logged + Pulse,
   Rize — лента дня. Там, где героя нет (Timing: 9 карточек и 7 графиков,
   ActivityWatch: 6 равных блоков, ManicTime: итог мелким внизу), обзоры это и
   ругают: «lots of information… a bit too much», «comprehensive, but scattered».
2. **Режимы разделены.** Rize (редизайн марта 2026) прямо развёл daily workflow
   и historical analysis: день — календарь с review, неделя/месяц — свои экраны.
3. **День строится слоями:** итог → лента → агрегированный список → сырые
   записи. Сырое всегда отдельно: ManicTime — Details, ActivityWatch — Raw Data,
   Toggl — Timesheet.
4. **Дешёвый доступ к двум главным вопросам.** RescueTime: день — 0 кликов,
   неделя — 1 клик.
5. **Цвет — только смысл.** Screen Time: топ-3 категории цветом, остальное серое.
6. **Сложность выносят** в вкладки экрана, отдельный раздел отчётов и настройки.

## Целевая архитектура

### Навигация: 4 → 3 раздела с подписями

`Сегодня` · `Неделя` · `Настройки`

«Работа» перестаёт быть экраном: переключатель «вся активность / только работа»
внутри «Сегодня» и «Недели», задачи по Jira — секцией в «Сегодня».

### «Сегодня» — четыре слоя

1. Строка состояния: что в фокусе + один герой-показатель, рядом разбивка.
2. Лента дня высотой 96–120 px, три дорожки: активность, созвоны, AFK и
   пустоты; метка «сейчас»; hover с деталями.
3. «Куда ушло»: активность / AFK / не записано + «не размечено» с кнопкой.
4. Список приложений с drill-down до домена и окна; события — в drawer.

Убрать из «Сегодня»: вторую карточку итога, хронологический список на первом
плане. Цвет — три семантических (работа / нейтрально / отвлечение). Теги —
чипами на строке, не в контекстном меню.

### «Неделя» вместо «Статистики»

Четыре KPI с дельтой к прошлой неделе (активность, работа, созвоны, время без
ввода), stacked bars по дням, топ-10, heatmap отдельным переключателем.
Без score без расшифровки.

### Настройки

Плюс раздел «Правила и категории» с входом из «не размечено».
